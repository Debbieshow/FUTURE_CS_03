# FUTURE INTERNS - CYBERSECURITY
Task 3: Secure File Sharing System

## 📌Project Overview
This repository centres on building a secure file sharing system, that enables users upload and download files securely. This project fulfills the final requirements for the completion of the internship program with Future Interns.

## 🛠️Tools
- **Backend web framework:** Python Flask
- **Frontend basics:** HTML
- **AES encryption:** PyCryptodome

## 📂Folder Structure
```text
├── docs/
│   └── Security_document.pdf        
├── media/
│   └── live_demo           
├── secure_app_folder/
│   ├── templates/
│       └── index.html
│   ├── app.py
├── test_file
│   └── Interns_secret.txt (uploaded file)
```   

## 🚀How to Run the System
1. Clone this repository.
2. Ensure you have flask and pycryptodome dependencies installed.
3. Run the main script: `python app.py`.
4. Open http website` on the browser to view the interface.
5. Test the encryption by uploading a file.
6. Test decryption by downloading the file.
